# Athletic Performance 12-Week
// Strength, speed, agility and aerobic fitness for running, tennis and soccer.
// Mon lower / Wed upper / Thu speed / Fri full body. Tue easy run (35–50 min) and
// Sat sport or easy run (50–75 min) are logged as cardio. Sun rest.
// Leave 1–3 reps in reserve on most lifts. Jumps and sprints are never done to failure.
// Deload weeks: 4, 8 and 12.

## Week 1-3
// Technique and repeatable loads. Accessories get 2 sets. Keep sprints at 70–85%.

### Mon · Lower body power
Box Jump / 3x3 / bw / rest 2:00 / progress: none / full rest, quiet landing; fast calf raise if foot is sensitive
Squat / 4x5 / rest 3:00 / rpe 8 / progress: lp(5lb) / controlled depth, ~2 reps in reserve
Romanian Deadlift / 2x6-8 / rest 2:00 / progress: dp(5lb, 6, 8) / hip hinge, neutral back
Bulgarian Split Squat / 2x8 / rest 1:30 / progress: lp(5lb) / each leg; knee aligned, smooth eccentric
Standing Calf Raise / 2x10-12 / rest 1:00 / progress: dp(10lb, 10, 12) / full controlled range
Pallof Press / 2x10 / rest 1:00 / progress: none / each side; resist rotation, exhale and brace

### Wed · Upper body & rotation
Medicine Ball Rotational Throw / 3x5 / rest 1:30 / progress: none / each side; explosive, reset each throw
Bench Press / 3x6 / rest 2:30 / rpe 8 / progress: lp(5lb) / 1–2 reps in reserve
Pull-Up / 3x6-8 / bw / rest 2:00 / progress: dp(0, 6, 8) / strict; assisted or pulldown is fine
Dumbbell Row / 2x10 / rest 1:30 / progress: lp(5lb) / each side; no twisting through trunk
Half-Kneeling Landmine Press / 2x8 / rest 1:30 / progress: lp(5lb) / each side; ribs stacked, hips stable
Farmer Carry / 2x40s / rest 1:30 / progress: none / 30–40 m; tall posture, moderately challenging load
Dead Bug / 2x10 / bw / rest 0:45 / progress: none / each side; lower back controlled

### Thu · Speed & conditioning
// Warm up 8–10 min: jog, dynamic mobility, A-skips, lateral shuffles, two progressive accelerations.
Acceleration Sprint / 6x1 / rest 1:30 / progress: none / 10–20 m at 70–85%; walk back
5-10-5 Shuttle / 4x1 / rest 1:00 / progress: none / controlled; do 2 if needed in weeks 1–4
Lateral Shuffle / 3x15s / rest 1:00 / progress: none / plant and stop cleanly
Bike Intervals / 6x30s / rest 1:30 / progress: none / 30s hard, 90s easy; skip if foot or Achilles fatigue builds
// Cool down 5–8 min: easy walk, calf and hip mobility.

### Fri · Full-body athletic strength
Lateral Bound / 3x4 / bw / rest 1:30 / progress: none / each side; stick the landing 2 sec, small distances first
Trap Bar Deadlift / 3x5 / rest 3:00 / rpe 8 / progress: lp(10lb) / strong drive, no grinding reps
Lateral Lunge / 2x8 / rest 1:30 / progress: lp(5lb) / each side; hips back
Single-Leg Romanian Deadlift / 2x8 / rest 1:30 / progress: lp(5lb) / each side; level hips
Copenhagen Plank / 2x20s / bw / rest 1:00 / progress: none / each side; start from the knee, stop if groin pain
Seated Calf Raise / 2x12 / rest 1:00 / progress: lp(10lb) / slow lowering
Cable Chop / 2x10 / rest 1:00 / progress: lp(5lb) / each side; rotate deliberately
